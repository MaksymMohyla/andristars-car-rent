# Landing Page Project

This is a responsive landing page built using **HTML**, **CSS**, and **JavaScript**. The project demonstrates clean and modular code structure, focusing on modern web development best practices.

## Features

- **Responsive Design**: The layout adapts seamlessly to various screen sizes, ensuring an optimal user experience across devices.
- **SCSS for Styling**: Stylesheets are written in **SCSS**, providing better organization, reusability, and maintainability.
- **BEM Methodology**: The code follows the **BEM (Block, Element, Modifier)** methodology, ensuring consistent and scalable naming conventions for CSS classes.
- **Interactive Elements**: Implemented smooth menu opening and closing with vanilla JavaScript. All the other interactive elements have hover effect or cursor pointer upon them.

## Technologies Used

- HTML5
- SCSS (compiled to /src/styles/index/index.css)
- JavaScript (ES6+)

## To open the page locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/MaksymMohyla/andristars-car-rent.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Install `Live Server` extension for VSCode or other IDE that you use.

4. Run `/index.html` file with `Live Server`. Check the browser for opened tab (http://127.0.0.1:5500/).
